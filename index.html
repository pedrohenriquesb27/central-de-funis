Estrutura da Tabela 'quiz_leads'

Instrução SQL para suporte à coluna 'funil_id'

A Central de Funis funciona dinamicamente conectada à tabela quiz_leads. Se a coluna funil_id ainda não tiver sido criada no seu painel Supabase, execute o comando abaixo no SQL Editor do Supabase:

ALTER TABLE quiz_leads ADD COLUMN IF NOT EXISTS funil_id TEXT DEFAULT 'quiz_prosperus';

* Os leads existentes que tiverem funil_id nulo são automaticamente associados ao Funil 1: Quiz Prosperus.
