Como Rastrear os Funis via Webhook da Greenn

URLs e parâmetros para capturar Nome, Telefone e Vendas automaticamente

Como o rastreamento funciona em 2 passos simples:

1. No Checkout da Greenn: Ao cadastrar a URL de Webhook abaixo na Greenn, qualquer pessoa que digitar Nome e Telefone/WhatsApp no checkout (mesmo se abandonar!) será enviada instantaneamente para a Central de Funis.
2. Identificação do Funil: O webhook identifica automaticamente se a origem foi a Página Principal, o Funil 02 ou o Quiz.

1. URLs de Webhook para Cadastrar na Greenn (Configurações > Webhooks)

Prosperus Principal (www.prosperusif.com.br)
https://central-de-funis-zeta.vercel.app/api/webhook-greenn?funil=prosperus_principal
Prosperus Funil 02 (prosperus-02.vercel.app)
https://central-de-funis-zeta.vercel.app/api/webhook-greenn?funil=prosperus_funil_02
Quiz Prosperus (prosperus-quiz.vercel.app)
https://central-de-funis-zeta.vercel.app/api/webhook-greenn?funil=quiz_prosperus

2. Links de Checkout com Rastreamento para os Botões das Páginas

Nos botões de compra de cada página, use o parâmetro &src=... no final da URL do checkout da Greenn. Assim a Greenn envia a origem automaticamente:

Principal: https://payfast.greenn.com.br/27s9n8q?src=prosperus_principal
Funil 02: https://payfast.greenn.com.br/27s9n8q?src=prosperus_funil_02
Eventos para marcar no Webhook da Greenn:
  • ✅ Abandono de Carrinho / Checkout (captura Nome e Telefone preenchidos)
  • ✅ Pix Gerado / Aguardando Pagamento
  • ✅ Venda Aprovada / Compra Realizada (registra a receita e atualiza para Comprou)

Instrução SQL para suporte à coluna 'funil_id'

Para permitir gravar a coluna funil_id diretamente no Supabase, execute o comando abaixo no SQL Editor do painel Supabase:

ALTER TABLE quiz_leads ADD COLUMN IF NOT EXISTS funil_id TEXT DEFAULT 'quiz_prosperus';
